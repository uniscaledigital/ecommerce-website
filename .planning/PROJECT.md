# The Irish Grocer Storefront

## What This Is
The Irish Grocer is a premium e-commerce storefront specializing in authentic Irish food, beverages, and pantry staples imported from Ireland. Built with Next.js 15, React 19, TypeScript, and Tailwind CSS, it features a warm heritage visual identity (Irish green, cream, and gold).

## Current Status
- **Milestone v1.0 (Shipped)**: Frontend Demo Remediation & Client Acceptance Verification (US-001 through US-007, 38 passing tests, clean build, client acceptance report).
- **Milestone v2.0 (Active Scope)**: Advanced Product Filtering & Discovery.

## Core Value
Shoppers can effortlessly discover, refine, and browse authentic Irish products through intuitive, faceted filtering and layout controls across desktop and mobile devices.

## Active Milestone: Advanced Product Filtering & Discovery (v2.0)

### Objectives
1. Multi-faceted filtering across 7 dimensions (Availability, Category, Brand, Price Range, Product Type, Dietary & Lifestyle, Rating).
2. Desktop vertical sidebar with active filter chips, sort dropdown, and grid/list view toggle matching Irish Grocer brand design.
3. Flipkart-style mobile slide-in drawer with expandable sections, touch-friendly tap targets, and sticky bottom "Apply Filters (N)" action.
4. Accurate dynamic facet counts and matching product counts calculated directly from real catalogue data with zero hardcoded numbers.
5. Strict AND/OR filtering logic: AND between filter groups, OR within multi-select groups.
6. Seamless URL query parameter deep linking and bookmarking.
7. Preserve standalone mock-data demo mode (`NEXT_PUBLIC_COMMERCE_MODE=demo`), cart, wishlist, and existing visual identity.
