# Plan 20-02: Multi-Surface Heart Synchronization

## Objective
Unify the wishlist heart interaction across all product surfaces (`ProductCard`, `ProductListCard`, `QuickViewModal`, and `ProductDetailsClient`) to guarantee consistent state, immediate reactivity, and canonical product identification (`product.id`).

## Tasks

### Task 1: Add Floating Heart Button to ProductListCard
- **Target:** `website/src/components/products/ProductListCard.tsx`
- **Actions:**
  1. Import `useWishlist` and `Heart` from `lucide-react`.
  2. Call `const { isWishlisted, toggleWishlist } = useWishlist(); const wishlisted = isWishlisted(product.id);`.
  3. In the image container, add top-right floating heart button matching `ProductImage.tsx`:
     - Dimensions: `w-11 h-11 min-w-[44px] min-h-[44px] rounded-full bg-white shadow-xs border border-[#D0E7C9]/80`.
     - Icon: `Heart` filled with `#22C55E` when wishlisted, outlined `#14532D` when not.
     - Event: `e.preventDefault(); e.stopPropagation(); toggleWishlist(product.id);`.
     - Accessible label: `aria-label={wishlisted ? "Remove from wishlist" : "Add to wishlist"}`.

### Task 2: Add Wishlist Heart Button to QuickViewModal
- **Target:** `website/src/components/products/QuickViewModal.tsx`
- **Actions:**
  1. Import `useWishlist` and `Heart`.
  2. Call `const { isWishlisted, toggleWishlist } = useWishlist(); const wishlisted = isWishlisted(product.id);`.
  3. In the product image showcase, add floating heart button in top-right or top-left corner with `w-11 h-11 min-w-[44px] min-h-[44px]`.
  4. Clicking heart toggles wishlist state for `product.id` and immediately updates icon fill and bottom navigation badge.

### Task 3: Add Styled Heart Toggle Button to ProductDetailsClient (PDP)
- **Target:** `website/src/app/products/[handle]/ProductDetailsClient.tsx`
- **Actions:**
  1. Import `useWishlist` and `Heart`.
  2. Call `const { isWishlisted, toggleWishlist } = useWishlist(); const wishlisted = isWishlisted(product.id);`.
  3. In the commerce action block next to the Quantity Stepper and Add to Cart button, add a dedicated styled heart button:
     - Minimum dimensions: `w-11 h-11 sm:w-12 sm:h-12 min-w-[44px] min-h-[44px] rounded-full border`.
     - Visual state: Active = `bg-[#DDF1D5] border-[#22C55E] text-[#14532D] shadow-xs` with filled heart; Inactive = `bg-white border-[#D0E7C9] text-[#14532D] hover:bg-[#FDF4E3]`.
     - Accessible ARIA: `aria-label={wishlisted ? "Remove from Favourites" : "Save to Favourites"}` and `aria-pressed={wishlisted}`.

## Verification Criteria
- Clicking heart on any surface immediately toggles the icon to filled and updates the bottom navigation badge.
- Clicking active heart removes the product from saved items.
- All components reference the exact same canonical `product.id`.
- `ProductCard.tsx` design invariants remain 100% protected.
