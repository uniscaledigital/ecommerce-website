# Plan 20-03: Dedicated /favorites Route & Farmhouse Empty State

## Objective
Author a dedicated, beautifully branded `/favorites` destination page displaying saved products in the standard 2-column mobile and multi-column desktop grid, complete with sorting, batch "Add All to Basket" CTA, immediate heart removal, and an authentic farmhouse empty state when 0 items are saved.

## Tasks

### Task 1: Create Server Route Page (src/app/favorites/page.tsx)
- **Target:** `website/src/app/favorites/page.tsx`
- **Actions:**
  1. Author Next.js App Router server component.
  2. Define SEO metadata:
     - `title`: `"My Favourites — The Irish Grocer"`
     - `description`: `"Your saved authentic Irish groceries and farmhouse provisions."`
  3. Render client view: `<FavoritesClientView />`.

### Task 2: Create Client View Component (src/app/favorites/FavoritesClientView.tsx)
- **Target:** `website/src/app/favorites/FavoritesClientView.tsx`
- **Actions:**
  1. Mark as `"use client"`.
  2. Import `useWishlist`, `PRODUCTS`, `ProductCard`, `useCart`, `useAuth`, `formatMoney`, `Heart`, and `ArrowRight`.
  3. Safe hydration: use `isMounted` state to prevent SSR empty state flashing before localStorage loads.
  4. Derive saved products: `PRODUCTS.filter(p => wishlist.includes(p.id))`.
  5. Implement sorting state (`sortOption`): Alphabetical A-Z, Price: Low to High, Price: High to Low, Customer Rating.
  6. **Header Section:**
     - Playfair Display heading: `My Favourites`.
     - Subtitle: `Your saved Irish groceries, all in one place.`
     - Dynamic count badge: `{savedProducts.length} {savedProducts.length === 1 ? "item" : "items"} saved`.
     - Controls row: Sort dropdown + secondary `Clear All` action button (if `savedProducts.length > 0`).
  7. **Batch Action CTA ("Add All Available to Basket"):**
     - When `savedProducts.length > 0`:
       - If authenticated: render primary CTA button `Add All to Basket` that iterates through all in-stock saved items, adds them to cart via `addItem(product)`, and opens CartDrawer via `openCart()`.
       - If unauthenticated: render `Log in to add saved items to basket` linking to `/account/login`.
  8. **Product Grid:**
     - Render responsive grid: `grid-cols-2 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-3 sm:gap-5 lg:gap-6`.
     - Use existing `ProductCard` for every product.
     - Direct removal: clicking card heart removes item from `useWishlist`, updating grid and bottom navigation badge instantly without page reload.
  9. **Empty State (`savedProducts.length === 0`):**
     - Warm Cream card (`#FFFAF1`), border `#E8DFCF`, rounded-2xl, p-8 sm:p-12 text-center shadow-xs.
     - Heart icon / illustration in mint circle background (`#EDF8E9` / `#22C55E`).
     - Heading: `No favourites yet` (Playfair Display 2xl text-[#14532D]).
     - Description: `Save the products you love by tapping the heart icon. They'll appear here for easy shopping.`
     - CTA Button: `Discover Products` linking to `/shop` (Forest Green `#14532D`, min-h-[44px], rounded-full).
  10. Cart independence: ensure saving/removing favourites never mutates cart state.

## Verification Criteria
- `/favorites` renders saved products in 2-column mobile / multi-column desktop grid.
- Removing a product updates the grid and bottom nav badge immediately.
- Empty state renders with correct copy and `Discover Products` link.
- Batch CTA adds items to cart and honors wholesale login gating.
