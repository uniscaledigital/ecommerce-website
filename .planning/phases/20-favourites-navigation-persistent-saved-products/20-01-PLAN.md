# Plan 20-01: Storage Engine Audit & Bottom Navigation Integration

## Objective
Harden the existing `useWishlist` hook with Set deduplication, safe JSON parsing, and reactive count methods while preserving backward compatibility; update `MobileBottomNav.tsx` to 6 equal-width destinations (Home, Shop, Search, Favourites, Cart, Account) with active heart styling and a live numeric badge.

## Tasks

### Task 1: Audit & Harden useWishlist Storage Engine
- **Target:** `website/src/hooks/useWishlist.ts`
- **Actions:**
  1. Retain storage key `const WISHLIST_STORAGE_KEY = "irish_grocer_wishlist"`.
  2. Implement defensive JSON parsing: catch malformed JSON and ensure the result is an array. If invalid or corrupt, safely reset to `[]`.
  3. Ensure strict Set deduplication on initial load and toggle mutations:
     `const sanitized = Array.from(new Set(arr.filter((id) => typeof id === "string" && id.trim())));`
  4. Expose `wishlistCount: wishlist.length`.
  5. Add `clearWishlist: () => void`:
     - Resets state `setWishlist([])` and `wishlistRef.current = []`.
     - Sets `localStorage.setItem(WISHLIST_STORAGE_KEY, "[]")` (or removes item).
     - Dispatches `window.dispatchEvent(new Event("wishlist-updated"))`.
  6. Maintain the dual-event model: `wishlist-updated` for immediate same-tab component reactivity and `storage` for cross-tab synchronization.

### Task 2: Update MobileBottomNav to 6 Equal-Width Destinations
- **Target:** `website/src/components/layout/MobileBottomNav.tsx`
- **Actions:**
  1. Import `Heart` from `lucide-react` and `useWishlist` from `@/hooks/useWishlist`.
  2. Determine active state: `const isFavoritesActive = pathname === "/favorites";`.
  3. Update container from `grid-cols-5` to `grid-cols-6 h-16 items-center px-0.5 sm:px-1`.
  4. Render 6 destinations in strict order:
     1. **Home:** Link to `/`, label `Home`.
     2. **Shop:** Link to `/shop`, label `Shop`.
     3. **Search:** Link to `/search`, label `Search`.
     4. **Favourites:** Link to `/favorites`:
        - Inactive icon: `<Heart className="w-5 h-5 text-current" />`
        - Active icon: `<Heart className="w-5 h-5 text-[#14532D] fill-[#14532D]" />`
        - Label: `Favourites` (`text-[9px] xs:text-[10px] mt-0.5 tracking-tight truncate max-w-full text-center leading-none`)
        - Active background: `bg-[#14532D]/10 text-[#14532D] font-bold` when `isFavoritesActive`
        - Live badge: when `wishlist.length > 0`, render `<span className="absolute -top-1 -right-1 bg-[#22C55E] text-[#14532D] text-[10px] font-black w-4 h-4 rounded-full flex items-center justify-center shadow-xs border border-white">{wishlist.length}</span>`
     5. **Cart:** Button calling `openCart`, label `Cart`, dynamic cart item badge.
     6. **Patrick / Account:** Link to `/account`, label `customer?.firstName || "Account"`.
  5. Responsive verification: Verify each column has width $\ge 59.3\text{px}$ on 360px, $\ge 64.3\text{px}$ on 390px, and $\ge 71.0\text{px}$ on 430px viewports with $\ge 44\times 44\text{px}$ tap targets.

## Verification Criteria
- `useWishlist` correctly stores unique product IDs and broadcasts events.
- `MobileBottomNav` displays 6 destinations in exact order with responsive widths and live badge.
