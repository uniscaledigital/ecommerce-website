# Plan 20-04: Automated Test Suite, Static Toolchain & Gravitas Verification

## Objective
Author a comprehensive automated regression test suite covering all 20 functional scenarios, run all 4 static quality gates, and conduct Gravitas headless Chrome CDP multi-viewport browser testing across 10 viewports to verify zero errors, zero horizontal overflow, and strict visual preservation.

## Tasks

### Task 1: Author Dedicated Automated Test Suite
- **Target:** `website/tests/phase20-favorites.test.ts`
- **Actions:**
  1. Author test suite with `node:test` and `node:assert/strict`.
  2. Test scenarios covered:
     - `useWishlist` persistence: saving item stores to `localStorage` under `irish_grocer_wishlist`.
     - `useWishlist` deduplication: duplicate IDs are filtered out via Set.
     - `useWishlist` malformed data: handles non-array/corrupted JSON safely without crashing.
     - `useWishlist` cross-tab events: updates state on `storage` and `wishlist-updated` events.
     - `MobileBottomNav` layout: validates exact 6 destinations in order (Home, Shop, Search, Favourites, Cart, Account).
     - `MobileBottomNav` Favourites tab: validates Heart icon active/inactive classes and live badge count rendering.
     - `MobileBottomNav` touch targets: verifies $\ge 44\times 44\text{px}$ touch targets across 360px, 390px, 430px.
     - `FavoritesClientView`: derives matching catalogue products, handles invalid/deleted product IDs safely.
     - `FavoritesClientView`: validates sorting invariants (A-Z, price low-high, price high-low, rating).
     - `FavoritesClientView`: empty state copy and `Discover Products` link verification.
     - `FavoritesClientView`: batch Add All to Basket CTA and B2B wholesale pricing gate.
     - Multi-surface heart wiring: asserts `ProductListCard`, `QuickViewModal`, and `ProductDetailsClient` wire heart toggles to `useWishlist`.
     - Cart independence: verifies favouriting has zero effect on cart items or totals.
     - Shared component preservation: verifies `ProductCard.tsx` design invariants remain protected.
  3. In `website/package.json`, update `"test"` script to include `tests/phase20-favorites.test.ts`.

### Task 2: Static Quality Gates Execution
- **Target:** Terminal
- **Actions:**
  1. Run `npm test` $\rightarrow$ verify 100% pass across all 8 suites.
  2. Run `npx tsc --noEmit` $\rightarrow$ 0 errors.
  3. Run `npm run lint` $\rightarrow$ 0 warnings, 0 errors.
  4. Run `npm run build` $\rightarrow$ compile all 33 routes including `/favorites`.

### Task 3: Gravitas Multi-Viewport & Visual Regression Audit
- **Target:** Headless Chrome CDP via `scratch/phase20_verification.cjs`
- **Actions:**
  1. Test 10 viewports: 360px, 390px, 430px, 768px, 820px, 1023px, 1024px, 1280px, 1440px, 1920px.
  2. Execute 20 functional scenarios:
     - Click heart on Home card $\rightarrow$ heart fills $\rightarrow$ badge increments.
     - Navigate to `/favorites` $\rightarrow$ saved product appears.
     - Page refresh $\rightarrow$ product persists.
     - Save another product from PDP $\rightarrow$ `/favorites` shows both items.
     - Remove one product $\rightarrow$ badge decrements immediately $\rightarrow$ grid updates.
     - Clear all $\rightarrow$ empty state displays with `Discover Products` link to `/shop`.
     - Save inside collection $\rightarrow$ appears in `/favorites`.
     - Verify cart independence.
  3. Check horizontal overflow: `scrollWidth <= innerWidth` across all 10 viewports (0 overflow).
  4. Runtime health: 0 console errors, 0 uncaught exceptions.
  5. Visual baseline comparisons: compare desktop viewports ($\ge 1024\text{px}$) against Phase 18 baselines ($\ge 95\%$ similarity).

## Verification Criteria
- All 8 automated test suites passing.
- 0 TypeScript compiler errors, 0 ESLint warnings, 0 build errors.
- 0 runtime console errors, 0 uncaught exceptions.
- 0 horizontal overflow across all 10 viewports.
- Strict design preservation confirmed with $\ge 95\%$ visual similarity on existing approved pages.
