# Plan 21-03: Gravitas Multi-Viewport CDP Browser Audit & CodeRabbit Review

## Objective
Execute real browser automated testing via Chrome DevTools Protocol across 10 viewports (360px–1920px) to verify desktop header Favourites interactions, live badge reactivity, strict mobile design freeze, zero console errors, zero horizontal overflow, and perform CodeRabbit static review.

## Tasks

### Task 1: Author Gravitas CDP Verification Script
- **Target:** `scratch/phase21_verification.cjs`
- **Actions:**
  1. Audit 10 viewports: 360px, 390px, 430px, 768px, 820px, 1023px, 1024px, 1280px, 1440px, 1920px.
  2. Verify 0 horizontal overflow (`scrollWidth <= innerWidth`) on all 10 viewports.
  3. Execute desktop functional scenarios on 1024px, 1280px, 1440px, 1920px:
     - Heart appears between Account and Cart in desktop header.
     - Badge count reflects existing wishlist in real time.
     - Saving a product from a card updates desktop badge immediately.
     - Removing a product updates badge immediately.
     - Clearing all favourites hides the zero-count badge.
     - Clicking the heart navigates directly to `/favorites`.
     - Active heart appearance is correct on `/favorites`.
     - Header remains floating sticky at `top: 16px`.
  4. Execute mobile design freeze verification on 360px, 390px, 430px:
     - All 6 mobile bottom nav destinations remain in exact order (`Home`, `Shop`, `Search`, `Favourites`, `Cart`, `Account`).
     - No additional mobile header heart appears.
     - No mobile layout or typography changes.
  5. Capture before-and-after screenshots across viewports.
  6. Verify 0 runtime console errors and 0 uncaught exceptions.

### Task 2: CodeRabbit Code Review
- **Actions:**
  1. Review modified files (`src/components/layout/Header.tsx`, tests).
  2. Verify null safety, event listener cleanup, accessible name, focus indicators, and strict mobile isolation.

### Task 3: Comprehensive Acceptance Report
- **Actions:**
  1. Author `PHASE_21_ACCEPTANCE_REPORT.md` documenting all test evidence, screenshots, metrics, and freeze confirmations.
  2. Update `.planning/STATE.md` and `.planning/ROADMAP.md`.

## Verification Criteria
- 10/10 viewports verified with 0px horizontal overflow.
- All desktop functional scenarios passed.
- Mobile design freeze strictly confirmed.
- 0 console errors, 0 uncaught exceptions.
- CodeRabbit review clean.
