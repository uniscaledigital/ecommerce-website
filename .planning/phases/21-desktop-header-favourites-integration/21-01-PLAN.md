# Plan 21-01: Desktop Header Favourites Action & Live Badge Integration

## Objective
Update `website/src/components/layout/Header.tsx` to add a dedicated, accessible, and responsive Favourites heart navigation action to the desktop action controls row on screens $\ge 1024\text{px}$, placed between Account and Cart, complete with live numeric badge count, active route highlight, and strict mobile isolation.

## Tasks

### Task 1: Component Imports & Wishlist State Hook
- **Target:** `website/src/components/layout/Header.tsx`
- **Actions:**
  1. Import `Heart` from `lucide-react`.
  2. Import `useWishlist` from `@/hooks/useWishlist`.
  3. Inside `Header()`, consume `const { wishlistCount, isLoaded } = useWishlist();`.
  4. Derive active state: `const isFavoritesActive = pathname === "/favorites";`.

### Task 2: Insert Desktop Favourites Action in Action Row
- **Target:** `website/src/components/layout/Header.tsx`
- **Actions:**
  1. Locate the desktop action controls row (`hidden lg:grid ...`):
     ```tsx
     {/* RIGHT: Action Controls (Store, Account, Cart) */}
     ```
  2. Between the Account Link and Shopping Cart Button, insert the Favourites navigation link:
     ```tsx
     {/* Favourites Control (Desktop Only: >= 1024px) */}
     <Link
       href="/favorites"
       className={`hidden lg:inline-flex items-center gap-1.5 text-xs xl:text-[13px] font-semibold text-[#14532D] hover:text-[#064E3B] hover:bg-[#14532D]/6 px-2.5 py-1.5 rounded-xl transition-all focus:outline-none focus-visible:ring-2 focus-visible:ring-[#14532D] ${
         isFavoritesActive ? "bg-[#14532D]/10 font-bold" : ""
       }`}
       aria-current={isFavoritesActive ? "page" : undefined}
       aria-label={`Favourites, ${wishlistCount} saved products`}
       title="Favourites"
     >
       <div className="relative">
         <Heart
           className={`w-4 h-4 transition-colors ${
             isFavoritesActive
               ? "fill-[#14532D] text-[#14532D]"
               : "text-[#14532D] hover:text-[#064E3B]"
           }`}
         />
         {isLoaded && wishlistCount > 0 && (
           <span className="absolute -top-1.5 -right-2 bg-[#22C55E] text-[#14532D] text-[10px] font-extrabold w-4 h-4 rounded-full flex items-center justify-center shadow-xs border border-white">
             {wishlistCount}
           </span>
         )}
       </div>
       <span className="hidden xl:inline">Favourites</span>
     </Link>
     ```
  3. Ensure no edits are made outside the `hidden lg:grid` block. The mobile header (`lg:hidden`) remains completely untouched.

## Verification Criteria
- Desktop action row displays: `Store` $\rightarrow$ `Account` $\rightarrow$ `Favourites` $\rightarrow$ `Cart`.
- Favourites heart links directly to `/favorites`.
- Outlined Heart when idle; filled `#14532D` Heart with background highlight when active on `/favorites`.
- Live badge displays `wishlistCount` when $> 0$, styled identical to Cart badge.
- Zero changes to mobile header or `MobileBottomNav.tsx`.
- TypeScript compiler passes with 0 errors (`npx tsc --noEmit`).
